# 01 后端单题练习实施计划

依据：`issues/01-backend-single-question-practice.md`，根目录需求 V1.5，以及用户指定目录中的阶段规格。执行授权：用户已指定 implement 01，沿用已确定的 FastAPI、SQLite 和接口测试边界，在当前分支实施。

## 接口与文件

- `backend/src/interview_backend/api.py`：标准响应、岗位包/可用性、创建/开始、提交、记录/报告和任务查询。
- `contracts.py`：请求及模型输出校验，服务端维度权重和证据子串校验。
- `store.py`、`schema.sql`：SQLite 事务、唯一约束、题目快照、答案/任务/评价持久化。
- `practice.py`：随机选题、版本冲突、幂等提交、后台评价及结果汇总。
- `model.py`：可配置模型 HTTP 边界；服务端密钥，不生成主问题。
- `samples.json`：两道自编已发布技术样题和一道未发布样题，保存来源与答案版本；不开放完整岗位包。
- `backend/tests/test_practice.py`：通过真实业务 API + SQLite 检查行为，仅替换外部模型 HTTP。
- `backend/scripts/acceptance.py`：通过运行中的 HTTP 服务执行真实模型单题验收并保存脱敏记录。

## 实施决定

- 预先同意的测试边界来自阶段规格 Testing Decisions：使用真实服务的业务接口；本项后端测试直接调用 HTTP API，不新建前端。
- 使用后台任务返回 202，GET 会话/任务轮询；当前只做单进程本地服务，持久化任务的自动接管留给 15。正常重试复用已有任务，不再次调用模型。
- 小样题包独立命名 `pack_agent_basics_sample`，不与正式岗位包发布状态混淆。使用已实际访问的 Anthropic 官方文章作为技术参考；题面与答案均自编并标注。
- 外部输出必须恰好包含五个维度，每维 0–100 或 null，且至少有一处当前回答的精确非空引文。总分、覆盖率和均分由服务端计算。
