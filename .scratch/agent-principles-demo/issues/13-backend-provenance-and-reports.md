# 13: 后端答案来源与错题反馈

**What to build:** 用户的评分和技术解释能追溯到当时的题目答案版本；只有真实核对过、支持对应结论的资料才成为可展示引用。用户可提交题目或评分疑问供维护者复核。

**Blocked by:** 01 后端单题练习真实闭环；03 后端题库发布与可用性。

**Status:** ready-for-agent

- [ ] 评分记录保存题目 ID、答案版本、答案来源状态和实际使用的资料证据；Agent 补答状态保留在内部数据中。
- [ ] 原题位置与独立技术依据分开保存；没有核对过的独立资料时不生成看似真实的资料引用。
- [ ] 答案范围外或有版本争议的技术结论按需检索；无直接证据时不作确定的新增结论，检索失败可定位。
- [ ] 报错记录包含题目 ID、答案版本、用户说明和处理状态；停用错题后新会话不再抽到它。
- [ ] 接口验收覆盖有依据引用、仅有原题来源、无依据争议和用户报错四种结果。
