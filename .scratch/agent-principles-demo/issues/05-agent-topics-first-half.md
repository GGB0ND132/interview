# 05: 发布 Agent 基础题前六主题

**What to build:** 用户能练习运行循环、应用架构、规划、上下文工程、记忆和工具调用六类基础题；这些题从固定来源整理，经校验与发布后进入真实候选池。

**Blocked by:** 03 后端题库发布与可用性。

**Status:** ready-for-agent

- [ ] 按固定取材版本记录这六个主题的全部基础题，保留原题 ID；源题无答案时可由 Agent 补写，明确记录答案来源和版本。
- [ ] 每题通过发布校验才计入可评分数；拒绝项及原因在发布结果中可查。
- [ ] 每个主题发布前人工抽查两题，优先包含 Agent 补答题，并记录核查材料、发现和结论。
- [ ] 抽查发现错误时停用错题并扩大同主题抽查；重复出现同类错误时暂停该主题评分直至修正和复查。
- [ ] 六个主题通过项可在单题练习中被实际抽到，发布结果与用户可见数量一致。
