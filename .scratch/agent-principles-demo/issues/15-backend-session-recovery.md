# 15: 后端会话恢复与失败重试

**What to build:** 两种模式的已保存问题、答案、任务、反馈和报告在页面刷新或服务重启后仍可读取；模型或检索失败时保持原答案并允许从失败阶段重试。01 已验证正常重启后读取单题记录，本项补齐模拟面试和进程中断后的任务接管。

**Blocked by:** 01 后端单题练习真实闭环；07 后端模拟面试编排与报告。

**Status:** ready-for-agent

- [ ] 服务端保存会话版本、当前题和阶段、已提交答案、生成任务、评价与报告，重启后可恢复已保存状态。
- [ ] 进程在模型调用中断后能识别未完成任务并安全接管；不把“重启后可读取完成记录”误报为任务接管已实现。
- [ ] 模型超时、非法输出、限流或检索失败时返回明确阶段和可重试动作；不保存半成品反馈，也不改用预设内容。
- [ ] 相同提交或重试不会生成第二份答案、题目或反馈；并发修改返回可处理的版本冲突。
- [ ] 模拟面试和试题练习分别通过接口完成恢复与失败重试验收，并核对最终历史只有一条有效结果。
