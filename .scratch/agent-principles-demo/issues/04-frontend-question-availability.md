# 04: 前端显示题库可用性与缺口

**What to build:** 用户选择练习模式和 Agent 基础档时，页面显示服务端实际可用的题数、可练主题及缺少的环节，避免把取材总数当成可评分题数。

**Blocked by:** 02 前端单题练习接入真实服务；03 后端题库发布与可用性。

**Status:** ready-for-agent

- [ ] 试题练习显示当前筛选条件下的真实可抽题数；无题时说明原因并阻止开始。
- [ ] 模拟面试显示必需环节与可覆盖主题的状态；覆盖不足时明确提示，不临时生成主问题填空。
- [ ] 发布和停用题目后，页面刷新能反映新的可用数及缺口。
- [ ] 浏览器验收覆盖有题、无题、环节缺失和题目停用四种外部状态。
