# 07: 后端模拟面试编排与报告

**What to build:** 用户通过服务端完成一场有开场、经历或情境、技术、行为和反问的 Agent 基础档模拟面试。系统从合格题中规划 3～4 个技术主题，按回答补问，并在结束时生成完整或说明缺口的部分报告。

**Blocked by:** 01 后端单题练习真实闭环；05 发布 Agent 基础题前六主题。

**Status:** ready-for-agent

- [x] 开场、经历或明确假设情境、技术、行为、候选人反问各有可发布的少量通用题与适用评价标准；通用题允许跨场次复用。
- [x] 只从题量足够且适合面试的已发布技术题中随机选 3～4 个主题，保存主题和题目选择；不把全部主题强制放进一场面试。
- [x] 追问聚焦本次回答和当前主问题，遵守次数上限与去重；不会生成未经发布的新主问题。
- [x] 每组更新未问、证据不足、已观察或不适用状态；通常约 7～8 道主问题，最多 12 道，防止无限补问。
- [x] 所需环节与优先能力证据充分时生成完整报告；用户结束、上限、题池耗尽或关键证据不足时生成说明原因的部分报告。详细分数只在结束后公开。
- [x] 通过真实会话接口跑完完整路径，并验证含糊、答错、不会和没有项目经历的分支不会错误标为完整。
