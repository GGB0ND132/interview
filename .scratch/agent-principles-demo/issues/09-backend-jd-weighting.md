# 09: 后端 JD 能力映射与加权选题

**What to build:** 用户粘贴 JD 文本并确认提取出的要求后，模拟面试提高相关、已有合格题的 Agent 能力被选中的机会；无法覆盖的要求保留为明确缺口。

**Blocked by:** 07 后端模拟面试编排与报告。

**Status:** ready-for-agent

- [ ] 从 JD 文本提取明示要求和原文位置，映射到已维护能力；只有用户确认的映射参与选题。
- [ ] 在合格的 3～4 个主题内按 JD 要求加权但仍随机，保存候选池与抽选结果，不能因 JD 创建新主问题。
- [ ] 无相关已发布主问题的 JD 要求作为未覆盖项返回；用户可继续练习其他能力，报告仍显示该缺口。
- [ ] JD 仅用于岗位要求匹配和追问情境，不成为技术正确性的证据。
- [ ] 接口验收比较无 JD、有可覆盖 JD、含无法覆盖要求的 JD 三种会话，核对随机记录与缺口。
