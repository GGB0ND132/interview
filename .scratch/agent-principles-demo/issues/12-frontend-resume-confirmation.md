# 12: 前端简历上传与项目确认

**What to build:** 用户在模拟面试准备页上传简历、查看提取出的项目内容并确认；解析失败时可改为粘贴文本，之后看到与确认内容有关的经历问题或追问。

**Blocked by:** 08 前端模拟面试完整流程；11 后端简历项目解析与确认。

**Status:** ready-for-agent

- [ ] 页面支持文字版 PDF/DOCX 上传，显示处理进度、解析结果与可回查的项目片段。
- [ ] 用户可以确认或修正项目文本；未确认内容不进入会话。失败或不支持的文件有清楚提示和粘贴回退。
- [ ] 面试使用确认后的项目陈述提问；用户声明无项目经历时页面转入明确的情境分支。
- [ ] 浏览器验收覆盖上传确认、解析失败回退和无简历直接练习三种路径。
