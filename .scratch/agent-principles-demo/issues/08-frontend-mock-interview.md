# 08: 前端模拟面试完整流程

**What to build:** 用户从独立的模拟面试入口开始 Agent 基础档面试，在页面上依次看到环节题、针对回答的追问、进度和最终报告，而不会在进行中看到详细答案或分数。

**Blocked by:** 02 前端单题练习接入真实服务；07 后端模拟面试编排与报告。

**Status:** ready-for-agent

- [ ] 页面接入服务端的环节、题目、追问、处理状态与可用操作，不再用固定五题和定时器模拟面试推进。
- [ ] 面试中展示自然的环节与能力覆盖提示，隐藏详细评分和参考答案；完整或提前结束后展示对应报告和缺口。
- [ ] 用户可在合适状态继续、暂停或结束；服务端处理中重复操作有明确提示，不造成页面与会话状态分叉。
- [ ] 浏览器验收能完成一场包含五类环节的面试，并看到真实生成的完整或部分报告。
