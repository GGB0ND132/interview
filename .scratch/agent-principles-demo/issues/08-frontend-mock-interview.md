**Blocked by:** 02 前端单题练习接入真实服务；07 后端模拟面试编排与报告。

**Status:** ready-for-agent

- [x] 页面接入服务端的环节、题目、追问、处理状态与可用操作，不再用固定五题和定时器模拟面试推进。

- [x] 用户可在合适状态继续、暂停或结束；服务端处理中重复操作有明确提示，不造成页面与会话状态分叉。
