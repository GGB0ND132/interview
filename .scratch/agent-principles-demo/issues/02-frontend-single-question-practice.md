# 02: 前端单题练习接入真实服务

**What to build:** 用户从独立的试题练习入口选择 Agent 基础档，在页面上抽题、输入或空白提交答案，并立即看到真实反馈和历史记录。

**Blocked by:** 01 后端单题练习真实闭环。

**Status:** ready-for-agent

- [ ] 页面从服务端读取题目、可用动作、评价和历史，当前流程不再使用固定演示题或预设分数。
- [ ] 回答处理中显示状态；正常回答、空白提交和明确跳过分别呈现正确结果与计分说明。
- [ ] 用户刷新后可从已保存的会话读取已提交答案与反馈；失败或重复点击不会显示重复记录。
- [ ] 浏览器验收能完成一次真实随机单题、非空回答和即时反馈；模拟内容若仍可见，明确标为演示数据。
