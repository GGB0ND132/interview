# 16: 前端草稿恢复与重试操作

**What to build:** 用户在同一浏览器刷新后回到正确的当前题，保留尚未提交的文字；已提交答案从服务端恢复，失败时可以在页面重试且不会重复提交。

**Blocked by:** 08 前端模拟面试完整流程；15 后端会话恢复与失败重试。

**Status:** ready-for-agent

- [ ] 未提交文字按会话和当前轮次保存在同一浏览器；提交成功后清除对应草稿，刷新后只恢复与服务端当前题匹配的草稿。
- [ ] 两种模式刷新时从服务端恢复当前题、已提交答案、任务状态和可公开反馈，不以浏览器内存作为正式记录。
- [ ] 失败页面显示原因与重试动作；重复点击或重试后只出现一份答案和反馈。
- [ ] 浏览器验收覆盖两种模式的草稿刷新、已提交内容刷新、后端重启后的读取和模型失败重试。
