# 03: 后端题库发布与可用性

**What to build:** 维护者能从固定版本的 MianStack 标准题整理并发布一批 Agent 基础题，看到每题通过或拒绝的原因；用户只会抽到通过发布校验的题。

**Blocked by:** 01 后端单题练习真实闭环。

**Status:** ready-for-agent

- [ ] 固定取材版本，保存原题身份、分类、难度、来源定位、许可信息、答案来源状态和内容版本；第三方题集与面经不进入本批。
- [ ] 逐题检查题面、唯一 ID、能力与难度、完整答案、评分点和原题定位；缺项或占位内容不可评分。
- [ ] 发布预览列出接受数、拒绝数、每题原因和各主题可用数；只导入通过项，重复导入相同版本不复制题目。
- [ ] 对已发布题的答案或评分点修改会生成新版本，旧会话保留原版本；停用题不再进入新练习。
- [ ] 通过发布入口和练习可用性接口验证一批真实来源题；缺字段、重复 ID、无效定位和停用题均有可复现的拒绝记录。
