# 10: 前端 JD 确认与覆盖缺口

**What to build:** 用户可在模拟面试开始前粘贴 JD、查看系统提取的 Agent 要求并确认；页面说明哪些要求可由题库覆盖，哪些不能覆盖但允许继续练习。

**Blocked by:** 08 前端模拟面试完整流程；09 后端 JD 能力映射与加权选题。

**Status:** ready-for-agent

- [ ] 页面提供 JD 文本输入、提取结果预览和用户确认动作；未确认内容不参与本场选题。
- [ ] 可覆盖与不可覆盖的要求分别呈现；用户选择继续后，面试仍从已发布题库开始，报告保留缺口。
- [ ] 同一 JD 可以观察到相关合格主题的抽选权重变化，但界面不承诺每次都抽中某一主题。
- [ ] 浏览器验收覆盖无 JD、确认 JD 和未覆盖要求继续练习；JD 文件上传不作为本项验收。
