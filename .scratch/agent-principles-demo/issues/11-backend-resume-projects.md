# 11: 后端简历项目解析与确认

**What to build:** 用户上传文字版 PDF 或 DOCX 简历，服务端提取可查看的项目片段；用户确认后，模拟面试可把项目作为经历切入和当前主问题的追问情境。

**Blocked by:** 07 后端模拟面试编排与报告。

**Status:** ready-for-agent

- [ ] 文字版 PDF/DOCX 上传经过格式和大小检查，保留原文定位与提取出的项目片段；扫描件或解析失败有明确说明和粘贴文本回退。
- [ ] 解析结果需要用户确认；未确认片段不能影响面试选题或追问。
- [ ] 确认后的内容作为候选人陈述参与经历切入或相关追问，不视为外部核实的经历与成果，也不能充当技术答案依据。
- [ ] 用户确认无相关项目经历时，面试转入明确标注的假设情境题，不捏造履历。
- [ ] 通过接口验证上传、预览、确认、解析失败与无项目经历路径；个人学习资料知识库入库不在本项范围。
