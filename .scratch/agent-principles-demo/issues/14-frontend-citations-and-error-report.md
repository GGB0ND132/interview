# 14: 前端引用展示与报错入口

**What to build:** 用户在反馈和报告中看到可核实的资料引用，并能从具体题目反馈处报告题目或评分问题；没有独立资料的题不会显示虚构引用。

**Blocked by:** 02 前端单题练习接入真实服务；13 后端答案来源与错题反馈。

**Status:** ready-for-agent

- [ ] 资料引用打开后能查看真实保存的片段与来源；原题位置和技术资料依据有清楚区分。
- [ ] 没有核对过的独立资料时界面不显示假的文档、页码或片段；分数仍按已发布题库答案展示。
- [ ] 用户可提交题目或评分疑问，页面确认已收到；后台记录能定位到题目与答案版本。
- [ ] 浏览器验收覆盖有引用、无独立引用和提交报错三种路径。
