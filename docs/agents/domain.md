# Domain Docs

The engineering skills use one glossary and one ADR directory for this project.

## Before exploring

- Read root `GLOSSARY.md` when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If either is absent, continue. Domain-modeling creates these files when terms or decisions are resolved.

## Use project vocabulary

Use glossary terms in issue titles, proposals, hypotheses, and tests. If a needed term is missing, reconsider the wording or record the gap for domain-modeling.

## Flag decision conflicts

If a proposal contradicts an existing ADR, identify the conflict explicitly.
