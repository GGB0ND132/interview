## 已观察到的质量问题与后续工作

1. 技术题使用明确“不会、没有实践”的合成回答，报告仍给出技术均分 98，主要来自保留的表达等维度。`knowledge_gap` 与“已了解不等于掌握”虽保留，但高分容易造成误读。后续应单独设计不会/知识缺口的评分口径及报告呈现；本轮不宣称评分有效性通过，也不修改真实结果为更好看的分数。
2. 经历追问原文“你提到‘失败停止机制’，当时设定它不自动重试，是出于课程演示的简化考虑，还是因为发现重试可能引发状态不一致？”包含未被候选人明确提供的“不自动重试”前提。需要收紧追问的事实依据校验；不能把这次模型输出当成真实项目事实。
3. JD 明示词表未映射“能够处理失败重试”，虽然题库有恢复主题，页面按当前实现如实列缺口。后续可扩大有依据的别名映射并保持用户确认。
4. 原要求的人工抽查身份/结论和 GUI 第二道固定来源题仍欠缺，不能自动补填。05/06 既有 Agent 发布例外保留，但本次未获得修改 17 原始人工验收条款的指令。
5. 资料管理与独立历史页继续明确标注演示；个人资料入库、JD 文件、其他方向/难度与公开多用户仍不在本阶段范围。
