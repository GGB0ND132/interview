2026-11-12，在 `GGB0ND132/14` 完成。以主分支 `b5fdb7a` 为集成基线，接入已完成的 13 号后端提交 `3925bf3`。实现提交 `9e446cd`，后续提交补齐审查修正与本记录。

## 用户行为

- 单题反馈与真实模拟面试报告共用来源展示：分开呈现原题位置、答案版本和独立技术资料。支持资料可以展开查看保存的逐字片段、支持结论、核对时间和原文链接。
- 只有包含证据 ID、片段、支持结论、核对时间及正文摘要的保存记录才进入独立引用区；旧的纯链接不升级成技术证据。不生成文档、页码或片段。无独立引用时保留服务端分数并解释题库答案和评分点的计分依据。
- 每个单题反馈、报告题组均可报告问题。只在服务端创建成功后展示收件确认和编号；失败保留说明并可重试，提交期间防重复、显示加载与忙碌状态。字段错误映射到对应控件，顶部摘要提供定位链接；修改说明不丢失焦点。
- 报告按题组最后一个实际轮次提交，服务端从该历史题组快照绑定题目、答案版本和回答。空白 0 分可报告评分；明确跳过、无经历、无反问，以及被识别为这些情况的文字声明，仅允许报告题目。实际模型评价即使总分为 null，仍可提出评分疑问。

界面沿用 `UI.md` 的排版、颜色、表单和深浅色 token，复用反馈组件，未重做其他页面。独立历史页和资料管理仍保持其现有演示标识。

## 依赖集成

13 和 07 曾独立占用 schema 4，本分支统一升级至 schema 7。支持来源版 schema 4、面试版 schema 4、两种 schema 5 和主分支 schema 6；保留已存评分、引用、报错、JD 和简历。旧评分不重算，旧来源从对应单题或历史面试题组恢复，标记旧证据快照缺失，不追认旧链接。迁移与重启有专门回归。

模拟面试在题组出题时冻结核验资料，后续实际评分通过 13 的引用与争议核查流程，结束后的公开报告过滤内部补答信息。报错接口支持面试中的历史轮次，并拒绝其他会话的轮次及结束前的评分报错。
