# 11：后端简历项目解析与确认

## 实现范围

基于 07 已完成提交 `2ba2cff` 实现；该工作区原基点 `1888bae`，已快进补齐依赖。仅涉及后端和调用文档，前端确认页面属于 12。

提供上传、预览、确认、粘贴回退与会话快照。文字版 PDF 保存页码/提取行号，DOCX 保存正文段落序号（包含表格内段落）；保留提取原文，不保存原始二进制文件或客户端文件路径。原文和确认记录存储在本机 SQLite，不入个人学习资料知识库。

文件上限 5 MiB；最多 30 页 PDF / 50000 字提取原文；DOCX 解压条目上限 2000、展开总量 20 MiB，禁用 XML 外部实体。格式检查同时核对后缀、文件内容及文档结构。扫描件不进行 OCR，解析失败保存明确失败预览，提示粘贴项目文本或确认没有相关项目。

项目章节采用保守标题识别，片段按提取段落/行展示，不承诺任意简历布局都能自动分段；未识别时可查看全部提取原文并粘贴相关片段重试。PDF 的提取顺序和行号不是视觉坐标，DOCX 没有稳定页码。

用户确认时只能选择当前预览的片段 ID，或明确没有项目；两者互斥。确认后不可原地改写，修改需创建新预览。创建模拟面试引用 `config.resume_id` 时拒绝未确认记录，并在事务内保存只含所选片段的不可变快照。无资料仍可面试。

确认的项目用于已发布经历问题的切入和与当前技术主问题相关的追问情境；不新增主问题、不改参考答案或评分表。原文作为候选人陈述传入独立上下文，带有未经外部核实的声明；不进入技术引用。评分引文仍须出自实际回答。确认无项目时选择已发布假设情境题；面试中声明无经历也会清除后续上下文中的原项目。
