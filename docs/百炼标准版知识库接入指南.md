# 百炼标准版知识库接入指南

日期：2026-11-09。适用于本项目 M0 接入与内容验证。**系统库已有 11 份 Markdown 可通过已发布检索服务召回。**补传 `KB-BE-01` 后通过百炼 MCP 复跑固定 12 条主测，12 条预期资料均排第 1 位并支持答案。详见[百炼接入记录](content-baseline/评测/百炼接入记录_2026-11-09.md)。

## 当前接入状态与后续

1. 登录[阿里云百炼控制台](https://bailian.console.aliyun.com/)，选择中国站**华北 2（北京）**业务空间，确认知识库服务已开通，并在[业务空间管理](https://bailian.console.aliyun.com/)记下 `workspace_id`。知识库与后续 API Key 必须属于同一业务空间。首次开通的免费额度及其有效期以控制台显示为准。
2. 在[知识管理](https://bailian.console.aliyun.com/)确认已建库的规格为**标准版**、类型为**文档搜索**、向量存储为**内置**、向量模型为 `text-embedding-v4`；记下知识库 ID（`pipelineId`，控制台可能显示为知识库 ID 或 `index_id`）。
3. [`KB-BE-01_Python协程与任务.md`](content-baseline/知识资料/KB-BE-01_Python协程与任务.md)已补传并能从系统库召回。11 份资料的来源 ID 已在检索明细中记录；不要把 `知识资料_入库版/`、JD、评测题或来源清单同时导入系统技术库。
4. 已发布的[系统检索服务](https://rag.console.aliyun.com/rag/retrieval/aid-aa9147722c184458aae72ea8b942453a?tabKey=config)只绑定系统库。当前[检索评测集](content-baseline/评测/检索评测集.md)为 12/12；R01 至 R16 的固定主测均已复跑。最终召回最多 5 条；两条无依据题仍返回不相关片段，后端须判断证据是否足以回答。
5. MD、DOCX 的格式样本位于[接入样本目录](content-baseline/接入样本/)。它们只能放进临时的独立样本库，避免污染系统检索。PDF、DOC 由你补充后各准备一份普通文本样本，再按四种格式分别检查解析、索引、检索和来源字段。百炼官方支持 DOC 原格式，无需先安装 LibreOffice；仍须实测本项目样本。
6. 在同一业务空间创建[百炼 API Key](https://bailian.console.aliyun.com/)。Key 只放在后端本机配置或密钥管理中，**不要贴进聊天、前端 `VITE_` 变量或提交到项目文件**。保存 `workspace_id`、系统库 `pipelineId`、已发布检索服务 `agent_id` 和所选索引参数供后端接入。

## 后端接入时的固定口径

- 本项目保留 `KnowledgeProvider` 抽象，具体实现改为 `BailianAdapter`。业务数据库仍是 SQLite；百炼只负责知识资料的导入、索引与检索，面试会话和评分仍由 FastAPI 管理。
- 当前对话接入的百炼 MCP 已能用于资料检索和评测，但不会自动成为 FastAPI 的运行时知识库接口。后端仍须接入已发布的知识搜索 API，并在服务端保存 Key、`workspace_id` 和 `agent_id`。
- RAG API 基址为 `https://{workspace_id}.cn-beijing.maas.aliyuncs.com`。要使用控制台配置的查询改写、`qwen3-rerank`、阈值与最终召回数，应先发布知识检索服务，再调用 `POST /api/v1/indices/knowledge/search`，传 `agent_id` 与 `query`。单库底层 `POST /api/v1/indices/rag/index/retrieve` 不执行已发布检索服务的重排策略，仅用于原始召回诊断。返回切片需映射到本地文档版本与证据快照；不要把百炼知识问答生成结果直接当作本项目的评分或正式题目。
- 后端自动上传路径为：申请上传租约 → 按预签名 URL 上传原文件 → 注册数据中心文件 → 对已创建知识库提交导入任务 → 按 `ingestionId` 查询状态与文档切片。首次通过 API 建库时可使用“创建知识库并导入”接口；你在控制台已建库后使用“提交导入任务”，不要重复建库。
- 对已经在控制台手动导入的 11 份系统资料，先通过百炼文档列表取得远端文档 ID，按文件名与本地资料 ID 建立映射并抽查切片正文；本地另存原文件哈希。后端接管时不要再批量重复上传。
- 系统库先保持一个；个人知识库到 M4 需要个人资料时再创建。一个本地知识库对应一个百炼 `pipelineId`，并单独绑定一个检索服务 `agent_id`，系统与个人资料分别检索并在后端校验范围。标准版最高 1 QPS，批量入库和检索测试需控制请求节奏。
- 迁移后重新跑 M0 的四格式样本、12 条主测和来源映射；Dify 旧名次、旧切片 ID 与旧索引状态不能复用。页码或行号只有百炼实际返回或可可靠映射时才显示。

## 费用和资料边界

百炼标准版按知识库运行时长计费，官方标价为 **¥0.03／知识库／小时**，连续 30 天约 ¥21.60／库；Embedding、重排序或生成模型调用另计。一次性 720 库小时免费额度在有效期内按运行库数并行扣减；两个常开库会消耗双倍时长。创建库即开始计费，删除库才停止且会永久清除远端数据。因此先建系统库，样本库只在测试期保留，个人库到实际使用时再建。费用和免费额度以[官方计费说明](https://help.aliyun.com/zh/model-studio/billing-for-knowledge-base)及控制台账单为准。

技术资料保持本地原件；保留来源清单、文件哈希、本地文档版本与远端 ID 映射。删除远端库前先确认这些记录和原件齐全。用户提交的 JD、项目自述只作为岗位匹配或情境材料，不能充当技术答案的唯一依据。
