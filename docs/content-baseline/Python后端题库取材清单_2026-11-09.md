3. 首批下载件及哈希见[原始参考目录的下载记录](原始参考_Python后端_不入库/README.md)。它们只留在本地，不把整本手册、全部仓库或试题答案上传到百炼系统库。正式入库资料采用按能力整理的短篇中文原创概括，记录适用版本、官方 URL、资料 ID 和更新日期；是否可复制原文或上传第三方云端须按来源条款处理。
