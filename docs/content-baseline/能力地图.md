## 岗位依据映射

当前已有的 `docs/JD调研_2026-11-07.md` 和 `docs/智联技术岗位JD采集_2026-11-07.md` 可作为第一轮岗位能力线索：Python 后端参考 JD-NC-24828、ZL-03；前端参考 JD-NC-464885、ZL-01。它们分别提及 Python/Web 后端、MySQL/Redis，以及 HTML/CSS/JavaScript、React 或 Vue、前后端联调等要求。其他能力是项目内置岗位包的设计范围，不宣称这些 JD 都逐项要求。

## 明确缺口

- 后端：Python 语言基础、数据结构与算法、测试、日志排障、部署、网络基础和项目题依据尚未形成完整资料。MySQL 与 Redis 本批只覆盖入门到中级切片。
- 前端：HTML/CSS、DOM、可访问性、浏览器渲染、性能、前端测试、React/Vue 更深入的状态与路由实践尚未形成完整资料。
- 题库：本批无正式主问题、难度分层、评分要点和发布版本。不能据此开放任何方向。
- 来源：外部页面可能变动；正式发布前须由内容审核者复核技术结论及页面使用条件。
