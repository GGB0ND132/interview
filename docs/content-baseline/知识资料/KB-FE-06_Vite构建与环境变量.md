# Vite 构建与环境变量

资料 ID：KB-FE-06  
能力：FE-VITE  
适用范围：当前项目采用的 Vite 8 系列  
版本：0.1.0  
依据：S-VITE-01、S-VITE-02

## 开发与生产构建

Vite 开发服务器与生产构建承担不同工作。开发时利用浏览器原生模块等机制快速提供页面和更新；生产构建生成适合静态部署的输出。开发时能访问页面不代表生产构建已经通过，部署还需检查资源路径、路由回退和实际服务器配置。

## 模式与环境变量

Vite 根据模式读取相应的环境变量。客户端代码通过 `import.meta.env` 访问被暴露的值，默认只有 `VITE_` 前缀的自定义变量会进入客户端代码。暴露到前端的变量可能被用户从构建产物看到，因此 API 密钥、数据库密码和百炼 API Key 不应放在 `VITE_` 变量中。前端需要调用服务端接口，由服务端保管密钥。

## 构建时配置边界

构建时写入的前端环境值不等同于服务端运行时秘密。更换部署环境后，若变量在打包阶段已注入，可能需要重新构建或设计运行时配置入口。配置题应明确提问的是开发服务、构建过程还是部署后的请求流程。

## 面试判断边界

“变量放进 `.env` 就是秘密”不正确；是否进入客户端构建取决于暴露规则和代码使用方式。`VITE_` 前缀仅表示可供客户端访问，不表示安全保护。
