# React 状态与 Effect

资料 ID：KB-FE-04  
能力：FE-REACT  
适用范围：React 19 系列核心概念  
版本：0.1.0  
依据：S-REACT-01、S-REACT-02、S-REACT-03

## 状态快照

组件每次渲染会获得当次的 props 和 state 快照。事件处理函数读取的是创建该函数的那次渲染中的状态值；调用状态更新函数会请求新的渲染，并不会立即改写当前函数闭包中的变量。若一次事件中要基于前一个状态连续更新，使用函数式更新可以表达“以最新待处理状态为输入”。

## 不可变更新

数组和对象在 JavaScript 中可以原地修改，但 React 状态应视为不可变数据。新增、删除或修改数组项时，创建新的数组并交给状态更新函数；直接 `push` 旧数组再传回相同引用，会让状态变化难以正确表达和追踪。嵌套结构也要创建发生变化的那一层的新值。

## Effect 的职责

Effect 用于把组件状态与 React 之外的系统同步，例如浏览器 API、订阅或网络连接。依赖变化后可能需要重新同步，返回清理函数可撤销旧订阅或连接。仅为了根据现有 props/state 计算一个显示值，通常可以在渲染中计算，不必额外存一份状态再用 Effect 更新。

## 面试判断边界

“`setState` 后立刻读取变量就得到新值”忽略了渲染快照；“所有副作用都放在点击事件里”或“所有计算都放在 Effect 里”也没有区分用户事件与外部系统同步。
