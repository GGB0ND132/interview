# Python 协程与任务

资料 ID：KB-BE-01  
能力：BE-PY-ASYNC  
适用范围：Python 3.11 `asyncio`  
版本：0.1.0  
依据：S-PY-01

## 协程与 await

用 `async def` 定义的函数调用后产生协程对象；只调用函数不会自动执行协程。协程需要被 `await`，或包装成任务并交给事件循环调度。`await` 表示当前协程等待一个可等待对象；等待期间事件循环可以运行其他已就绪任务。它不等于把普通同步函数自动变成并行执行。

## Task 与并发

`asyncio.create_task()` 把协程安排为任务，让它能与当前协程并发推进。并发不等于多核并行：一个事件循环中的任务在等待 I/O 等操作时交替运行。若任务里直接调用长时间阻塞的同步代码，会阻塞事件循环，其他任务也难以及时推进。需要区分异步 I/O、普通同步阻塞调用和需要额外线程或进程处理的工作。

## 生命周期与取消

创建任务后应保留引用并处理完成、异常或取消。取消是协作性的：任务在可等待点收到取消请求，通常抛出 `CancelledError`。清理资源时可以捕获取消并在清理后继续传播；无条件吞掉取消会破坏上层的超时或任务组语义。超时机制通常通过取消相关任务来停止等待，因此面试回答不能只说“设置超时就一定立即结束所有工作”。

## 面试判断边界

“写成 `async def` 就一定更快”是错误概括。只有调用链能够在等待外部操作时让出控制权，异步结构才可能改善并发处理；具体吞吐和延迟还受数据库驱动、外部服务、阻塞代码及资源限制影响。
