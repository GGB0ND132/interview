# Vue 响应式与组件通信

资料 ID：KB-FE-05  
能力：FE-VUE  
适用范围：Vue 3 Composition API  
版本：0.1.0  
依据：S-VUE-01、S-VUE-02、S-VUE-03

## ref 与 reactive

`ref()` 创建带 `.value` 的响应式引用，适合基本值，也可包装对象。`reactive()` 创建对象的响应式代理。组合式代码中读取或修改 `ref` 要关注 `.value`；模板中常见的自动解包规则不能机械照搬到所有 JavaScript 上下文。拆解响应式对象的属性时也要注意是否保留响应式联系。

## computed

`computed` 描述依赖响应式数据的派生值。依赖不变时会缓存计算结果，依赖变化后再重新计算。它适合纯派生计算；需要与外部系统同步、处理异步动作或执行有副作用的操作时，应考虑事件处理或 watcher 等合适机制，而不是把所有逻辑塞进计算属性。

## 组件通信

父组件通过 props 向子组件传值，子组件通过事件向父组件报告动作。子组件不应直接把修改父组件传来的 prop 当成主要通信方式；对于对象或数组 prop，修改其内部属性也可能意外影响父组件状态。清楚地声明事件和数据流有利于组件复用与调试。

## 面试判断边界

“`computed` 每次渲染都会无条件重算”忽略缓存；“`reactive` 与 `ref` 在任何位置都完全等价”忽略了访问方式和解包规则。
