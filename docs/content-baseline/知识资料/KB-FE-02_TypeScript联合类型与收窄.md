# TypeScript 联合类型与收窄

资料 ID：KB-FE-02  
能力：FE-TS  
适用范围：TypeScript Handbook 当前所述类型规则  
版本：0.1.0  
依据：S-TS-01、S-TS-02

## 联合类型

联合类型表示值可能属于多个候选类型，例如 `string | number`。在未排除其他可能之前，只能调用所有候选类型都支持的操作。直接把联合值当成字符串使用，可能在数字输入时出错。

## 控制流收窄

TypeScript 能根据 `typeof`、条件分支、属性检查等控制流分析缩小类型范围。判别联合可为每种对象设置共同的字面量标记，例如 `kind: 'loading' | 'success' | 'error'`，再按 `kind` 分支处理。这样可以让编译器识别每个分支里可访问的字段，也有助于覆盖尚未处理的状态。

## 运行时边界

TypeScript 类型在编译为 JavaScript 后不会自动验证网络响应。即使把 `fetch` 返回的数据断言为某个接口，也不能证明服务端真的返回了那个结构。外部输入需要运行时校验或明确的错误处理。类型断言只改变编译器如何看待值，不会改变值本身。

## 面试判断边界

“用了 TypeScript 就不会有类型相关运行时错误”是错误结论。合理回答应区分编译期类型检查、控制流收窄和不可信外部数据的运行时验证。
