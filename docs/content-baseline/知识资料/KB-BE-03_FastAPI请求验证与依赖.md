# FastAPI 请求验证与依赖

资料 ID：KB-BE-03  
能力：BE-API  
适用范围：FastAPI 官方教程当前所述行为  
版本：0.1.0  
依据：S-FAST-01、S-FAST-02

## 请求数据来源

路径操作函数中的参数如何取值与声明方式有关：与路径模板匹配的参数来自路径，Pydantic 模型参数通常来自请求体。用模型描述输入结构，可以让 FastAPI 解析 JSON、执行字段验证，并把结构显示在生成的 API 文档中。校验失败应作为客户端输入错误处理；不能假设非法字段会自动被业务逻辑接受。

## 依赖注入

`Depends` 可以把公共操作声明为依赖，例如获取数据库连接、读取当前用户或检查权限。FastAPI 负责解析依赖关系并向路径操作函数传入结果。依赖可以复用，但不能只把代码移到依赖函数中就宣称安全：身份验证、授权范围、资源释放和异常路径仍要明确设计。

## 输入校验与业务规则

Pydantic 模型可检查字段类型和部分约束，但业务不变量要在业务层单独校验。例如“订单数量必须为正”适合输入模型约束；“同一用户不能重复领取同一张券”需要结合数据库状态和并发控制。请求体校验通过不等于业务写入一定成功。

## 面试判断边界

对 `Request` 原始对象直接读数据会绕开对应参数声明的自动验证和文档能力，因此需要说明为什么这样做以及如何补回必要校验。回答 FastAPI 的“自动校验”时，应指出校验对象和边界，而不是声称框架能替代所有业务判断。
